# Nail Art Studio public companion

Open **https://tomaatje93-cmd.github.io/nail-studio-assets/studio/** for polish/plate browsing, Colour Lab and Stamp Designer.

The original image gallery remains at the site root; `manifest.json` and existing image URLs are preserved. The companion is read-only. Catalogue updates are managed through the owner's Nail Studio chat and exported here; local hand-photo previews, favourites and downloads do not update catalogue records.

Only selected owned polish/plate fields, permitted product reference images and original stamp artwork are published. Private notes, personal photos, drafts, research narratives and PHP editors are excluded. Nail/stamp dimensions are approximate. Manufacturer references retain captions and attribution; candidate matches are not confirmed identities.

Publishing uses the repository's existing main-branch GitHub Pages setup. A new main commit updates the site after Pages finishes building. Refreshing the catalogue requires the owner's explicit public export; this repository does not access private records or hold repository credentials.
